# Security Policy

## Reporting a vulnerability in popeye itself

This repository is a fork of [derailed/popeye](https://github.com/derailed/popeye).
For vulnerabilities in the popeye codebase, please report upstream via that
project's security policy.

## Reporting a vulnerability in this fork's build artifacts

If you have found a vulnerability that is specific to **this fork** — for
example in our Dockerfile, our published container image at
`ghcr.io/nudgebee/popeye`, or our CI configuration — please report it by email
to **security@nudgebee.com**.

Please do not file public GitHub issues for suspected vulnerabilities.

We will acknowledge the report within five business days and aim to publish a
fix or mitigation in a tagged release once impact is understood.
